### To run the program: 
*Run the 'cell_phone_company_database.sql' file to initialize the tables \
*Make sure the pool parameters are correct for your machine \
*Run the server.js file and connect to localhost:3000 \
*Connect in a non safari web browser (ours was tested on chrome on multiple machines).

### To run the simulation:
*The default values should be fine, the simulation was primarily tested on these.\
*If much larger values are tested it could potentially break, however it works for the volume
guidelines specified by the TA \
*Click the "Update Bills" button to initialize empty tables for plans and then populate them based
on the previously generated data. Payments with cards by customers will also be simulated at this time
based on the input value. \

The customer portal is primarily for showing queries, paying bills, and enrollment while the admin portal is where the generation happens.

ExpressJS, Postgres, HTML/CSS
